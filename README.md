# HOI4 空戦シミュレーター

Hearts of Iron IV（HOI4）の「戦闘機 vs 戦闘機」を対象とした、ブラウザ上で動作する非公式の空戦シミュレーターです。

機体性能、航空隊数、探知率、作戦効率、戦闘回数などを入力し、連続空戦における撃墜数や残存機数を試算できます。同じ条件を多数回試行し、結果のばらつきや撃墜数分布を確認することもできます。

HTML・CSS・JavaScriptを1つのファイルにまとめているため、インストールやサーバー処理は不要です。

## 主な機能

- 戦闘機同士の空対空戦闘をシミュレーション
- 1航空隊を100機として固定
- 陣営A・陣営Bの機体性能を個別設定
- 1試行内の戦闘回数を設定
- 同一条件での試行回数を設定
- 戦闘損失を次戦へ持ち越す／毎戦リセットする方式を選択
- 通常空戦／空母戦を選択
- 手動探知率／Definesによる探知率推定を選択
- 航空隊ごとの確率的丸め
- 総撃墜、平均撃墜、残存機、撃墜比を表示
- 代表試行の戦闘ログを表示
- 複数試行の平均値、中央値、分位点、分布を表示
- 空戦Definesを画面上で変更
- `00_defines.lua` の初期値へ復元

## 動作環境

JavaScriptが有効な一般的なWebブラウザで動作します。

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

外部ライブラリ、外部API、Cookie、データベースは使用していません。入力値や計算結果は外部へ送信されず、すべて利用者のブラウザ内で処理されます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 戦闘回数と試行回数を入力します。
3. 陣営A・陣営Bの航空隊数と機体性能を入力します。
4. 損失を次戦へ持ち越すか選択します。
5. 必要に応じて詳細設定の空戦係数を変更します。
6. 「シミュレーション開始」を押します。
7. 代表試行、複数試行の統計、戦闘ログを確認します。

### 戦闘回数と試行回数

- **戦闘回数**：1つの試行内で実施する空戦回数です。
- **試行回数**：同じ条件の一連の空戦を、初期状態から何回再現するかを示します。

例えば「戦闘回数30、試行回数1,000」の場合、30回分の空戦を1セットとして1,000セット計算します。

### 損失の持ち越し

「損失を次戦へ持ち越す」を有効にすると、撃墜された機体は次の戦闘に参加できません。

無効にすると、各戦闘を毎回同じ初期機数から開始します。この場合も、総撃墜数は設定した全戦闘分を合計します。残存機数は最後に実施された1戦の結果です。

## 入力項目

陣営A・陣営Bには、それぞれ次の項目があります。

| 項目 | 内容 |
|---|---|
| 航空隊数 | 1航空隊100機として総機数を決定 |
| 航空攻撃 | 1機あたりの航空攻撃値 |
| 航空防御 | 1機あたりの航空防御値 |
| 機動性 | 相手との機動性比に使用 |
| 最高速度 | 相対速度・絶対速度ボーナスに使用 |
| 探知率 | 手動探知モードで発見できる敵機の割合 |
| 作戦効率 | 出撃可能な自軍機の割合 |

## 計算モデル

基本的な撃墜期待値は、保存版の Hearts of Iron IV Wiki「Air combat」に記載された次の構造を使用しています。

```text
撃墜期待値
= (基礎ダメージ
   - 機動性による軽減
   + 相対速度による加算
   + 絶対速度による加算)
  × 0.01
  × 戦闘係数
  ÷ 敵航空防御
```

基礎ダメージは次のように計算します。

```text
基礎ダメージ
= 参加機数
  × 航空攻撃
  × COMBAT_DAMAGE_STATS_MULTILPIER
```

攻撃参加機数は次の小さい方です。

```text
出撃可能な自軍機数

または

探知した敵機数 × COMBAT_MULTIPLANE_CAP
```

両陣営の攻撃は同時に計算され、同じ戦闘中に撃墜された機体も、その戦闘では反撃できます。

### 確率的丸め

撃墜期待値の小数部分は確率的に整数化します。

例えば期待値が `1.2機` の場合は、おおむね次のようになります。

- 80%の確率で1機
- 20%の確率で2機

この処理を敵の各航空隊に対して独立して行うため、同じ条件でも実際の撃墜数には幅が生じます。

## 探知処理

### 手動入力

入力された探知率を、そのまま発見できる敵機の割合として使用します。通常はこちらを推奨します。

### Definesから推定

次の要素を加算し、0～100%に制限した値を探知率として使用します。

- 支配地域割合
- レーダー寄与
- その戦闘時点の自軍残存機数
- 夜間補正

この処理は、指定された探知Definesをシミュレーターで比較するための推定モデルです。ゲーム内部の探知効率、天候、情報値、内部乱数などを完全には再現していません。

## 初期Defines

初期値には、提供された `00_defines.lua` から抽出した値を使用しています。

| Defines | 初期値 |
|---|---:|
| `COMBAT_MULTIPLANE_CAP` | 1.0 |
| `DETECT_CHANCE_FROM_OCCUPATION` | 0.10 |
| `DETECT_CHANCE_FROM_RADARS` | 0.5 |
| `DETECT_CHANCE_FROM_AIRCRAFTS` | 0.8 |
| `DETECT_CHANCE_FROM_AIRCRAFTS_EFFECTIVE_COUNT` | 1500 |
| `DETECT_CHANCE_FROM_NIGHT` | -0.2 |
| `COMBAT_DAMAGE_STATS_MULTILPIER` | 0.2 |
| `COMBAT_BETTER_AGILITY_DAMAGE_REDUCTION` | 0.9 |
| `BIGGEST_AGILITY_FACTOR_DIFF` | 2.0 |
| `COMBAT_BETTER_SPEED_DAMAGE_INCREASE` | 1.8 |
| `BIGGEST_SPEED_FACTOR_DIFF` | 3.5 |
| `TOP_SPEED_DAMAGE_BONUS_FACTOR` | 0.000 |
| `AIR_WING_MAX_STATS_SPEED` | 1000 |
| `COMBAT_DAMAGE_SCALE` | 1.00 |
| `COMBAT_DAMAGE_SCALE_CARRIER` | 3.00 |

詳細設定ではこれらの値を自由に変更できます。「00_defines.lua の値に戻す」を押すと、表の初期値へ復元されます。

## 資料に明記された処理と推定処理

### 資料に明記された処理

- 航空攻撃を使った基礎ダメージ
- 航空防御による除算
- 機動性差によるダメージ軽減
- 速度差によるダメージ加算
- `COMBAT_MULTIPLANE_CAP` による参加上限
- 最終損失の確率的丸め
- 通常空戦・空母戦のダメージ係数

### 再現のための推定処理

- 作戦効率を出撃可能機数へ直接乗算
- 同一性能の各100機航空隊へ、残存機数に比例して攻撃機を配分
- 航空隊単位で独立して確率的丸め
- 探知Definesから最終探知率を求める処理

画面上でも、この2種類をラベルで区別しています。

## 結果の見方

### 代表試行

多数試行のうち、最初に実行された1セットの具体的な結果です。戦闘ログと対応しています。

### 複数試行の統計

すべての試行から次の値を集計します。

- 平均総撃墜数
- 中央値
- 平均残存機数
- 優勢率
- 撃墜比
- 最小値、10%点、中央値、90%点、最大値
- 総撃墜数の分布

### 戦闘ログ

代表試行について、各戦闘の開始機数、参加機数、期待撃墜数、実撃墜数、残存機数を表示します。

## GitHub Pagesでの公開

このソフトは静的な1ファイル構成のため、GitHub Pagesで公開できます。

1. リポジトリ直下に `index.html` を配置します。
2. GitHubのリポジトリで `Settings` を開きます。
3. `Pages` を開きます。
4. Sourceを `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にします。
6. 保存し、公開処理の完了を待ちます。

公開URLは通常、次の形式です。

```text
https://ユーザー名.github.io/リポジトリ名/
```

## 既知の制限

- HOI4のゲームコードを直接実行しているわけではありません。
- Wikiで説明されていない内部処理は推定です。
- 航空隊は100機固定です。
- 異なる性能の機体が同一陣営に混在する編成には対応していません。
- 経験値、エース、天候、任務種別、補充、事故、燃料、航続距離は扱いません。
- 探知の内部乱数や情報値を完全には再現していません。
- ゲーム本体やMODの更新により、Definesや計算処理が変わる可能性があります。
- 試行回数、戦闘回数、航空隊数を極端に増やすと、計算に時間がかかる場合があります。
